# План: LLM Chat для Settings Hub (плавающая панель с вкладками)

> Запрос владельца (2026-11-09): «хочу добавить простенький ллм чат в мой
> settingshub чисто для общения, как стакер в отдельном окне. с поддержкой
> картинок и видео. и какую то интеграцию с комфи можно придумать
> взаимодействия с комфи из чата».
>
> Решения владельца (2026-11-09, уточнены нормальными вопросами):
> 1. Провайдер — **один формат: OpenAI-compatible URL + ключ (опционален)**.
>    Основной сценарий — локальные модели на PolyStrata-сервере, доступ по
>    IP:порту + опциональный api-токен. Тот же формат покрывает llama.cpp,
>    LM Studio, Ollama (/v1), vLLM, OpenRouter.
> 2. Диалоги — **несколько чатов одновременно на вкладках** внутри панели.
> 3. Медиа в v1 — **картинки к сообщению (vision)**; видео — следующая фаза.
> 4. ComfyUI-интеграцию — **на потом**: чат не агент, очередью и воркфлоу
>    не управляет.
> 5. План отдаётся в чате; интерфейс чата — **на английском**, как весь Hub.
>
> Исследование: пакет **PolyStrata** (локальная копия `work/polystrata_ref/`).
> Его сервер сам говорит на OpenAI-совместимом API (`/v1/chat/completions`,
> `/v1/models`, `/v1/load`, `/v1/unload`, `/v1/status`, порт по умолчанию
> 8080, `api_key` опционален — Bearer/x-api-key), картинки принимает как
> OpenAI-части `image_url` (base64 data-URL), thinking отдаёт через
> `reasoning_content`. Значит отдельный «провайдер PolyStrata» не нужен —
> достаточно одного OpenAI-compatible коннектора.
>
> Статус: **РЕАЛИЗОВАНО ЦЕЛИКОМ в v86** (обе фазы одним релизом: ядро + видео/стриминг/правка сообщений/загрузка модели). Тесты: tests/smoke_chat.mjs + tests/py_test_chat.py.

## 1. Принципы

1. **Плавающая панель, как стакер.** Тот же жизненный цикл: драг хедера,
   ресайз за grip, сворачивание в чип с бейджем, геометрия в localStorage
   (`settingshub.chat.ui`), v85-refit (`clampIntoView`/`refitIntoView`,
   пересборка при resize окна) с первого дня.
2. **Прокси на py-стороне.** Браузер НЕ ходит к LLM-серверу напрямую:
   `py/chat_proxy.py` — единая точка `/settings_hub/chat/*`, а дальше сам
   стучится к URL владельца. Причины: не надо настраивать CORS на
   PolyStrata-сервере (`cors_origins`), api-ключ не виден в F12 и не лежит в
   браузере, отмена генерации надёжно доезжает до апстрима, один контракт.
3. **Чат не агент.** Никаких инструментов, автоциклов, управления очередью
   ComfyUI. Чат общается — точка. Интеграции (мостики в стак, «в генерацию»)
   спаркованы, см. §7.
4. **Чат глобальный, не per-workflow** — общение не привязано к воркфлоу;
   разделяют его вкладки-чаты.
5. **Ядро скупое** («простенький, чисто для общения»): текст, картинки,
   вкладки, настройки. Всё остальное — фазы.

## 2. Окно и вкладки

- Хедер: `💬 Chat`, дропдаун модели (краткий бейдж), `🕘` сохранённые чаты,
  `[–]` свернуть в чип, `🗑` очистить текущий чат (двойное подтверждение,
  как у стека). Кнопки [✕] нет — Off только через настройки (контракт v75).
- **Вкладки чатов** под хедером: `[Дизайн-бриф] [Идеи] [+ ]` — каждая
  вкладка = отдельный диалог со своей историей. Двойной клик — переименовать,
  `✕` на вкладке — закрыть (диалог остаётся в 🕘). Открытые вкладки и
  активная — в localStorage.
- `🕘` — список сохранённых чатов сервера: открыть в новой вкладке, удалить
  (armed), наименование по первому сообщению.
- Лента: пузыри user/assistant; у thinking-моделей блок размышлений свёрнут
  (`reasoning_content`). Markdown-lite у ответов: ```-блоки кода с кнопкой
  копирования, `inline`, **жирный**, *курсив*, ссылки — ручной экранирующий
  рендер, без тяжёлых парсеров (XSS).
- Кнопки на сообщении: 📋 копировать, ↻ перегенерировать (v86); ✎
  редактировать своё и переотправить (v87).
- Ввод: textarea с авторостом до ~6 строк; Enter — отправить, Shift+Enter —
  перенос; ▶ / ⏹ (стоп = abort, прокси рвёт апстрим — у PolyStrata это
  штатный cancel «client went away»).
- Строка статуса: URL · модель · время/токены последнего ответа; ошибки —
  красным с человеческой причиной (паттерн note-диагностики v76). Набранный
  текст при ошибке/отмене не теряется.

## 3. Картинки (v86) и видео (v87)

- Способы прикрепить: 📎-кнопка, Ctrl+V над панелью, drag&drop файлов.
- Картинки png/jpg/webp → превью-чипсы над вводом (✕ снять, 🔍 — вьювер
  v83); уходят в запрос как `image_url` c base64 data-URL, длинная сторона
  ужимается (настройка) — формат, который PolyStrata принимает нативно.
- Лимиты: max сторона (def 1024 px), до N картинок на сообщение (def 4),
  JPEG quality (def 0.9).
- **Видео (v87):** браузер надёжно кадры не достаёт — нарезка на py-стороне
  (ffmpeg; нет ffmpeg/opencv — функция честно недоступна с причиной).
  N кадров равномерно (def 16) + блок `[Video N]` и метки `<X.X seconds>`
  — конвенция PolyStrata (mtmd), модель видит последовательность, а не
  стопку кадров. Кадры урезаются под контекст движка по оценке токенов
  (упрощённый `_fit_media_to_context` из ps_client).
- Текстовые файлы txt/md/json/csv/log/xml/yaml → содержимое в запрос
  (лимит ~300 КБ с маркером усечения); остальное — чип «файл» без отправки.

## 4. Подключение и модели

- Один коннектор: **Base URL + api-ключ (опционален) + имя модели**.
  Примеры URL: `http://127.0.0.1:8080/v1` (PolyStrata по умолчанию),
  `http://192.168.1.10:8080/v1` (LAN), `https://api.openai.com/v1`.
- Кнопка [Test] в настройках → через прокси `GET /v1/models` (+`/v1/status`
  если отвечает) → зелёная строка «модель X, загружена, контекст N» либо
  красная с причиной.
- Дропдаун модели: `GET /v1/models` ([⟳] перечитать) + ручной ввод.
  Полигон: у PolyStrata без `switch_on_request` в списке только загруженная
  модель — тогда в дропдауне она одна, честный статус. Выбор другой модели
  в v86 просто уходит полем `model` в запрос (серверы с router-режимом
  подхватят); принудительная загрузка `/v1/load` с предупреждением
  «грузится минуты» — v87.

## 5. Хранение (серверная сторона)

- Папка `user/settings_hub/chat/` (кастомный абсолютный путь — механика
  stackroot v84: проверка записи до переключения, отказ относительных).
  Переживает перезагрузки, общая для всех браузеров, едет с папкой ComfyUI.
- `config.json` — URL, api-ключ, модель, сэмплинг (ключ в браузер не
  возвращается никогда, UI показывает маску `****abcd`).
- `sessions/<id>/session.json` + `blobs/` — сообщения и вложения.
- localStorage — только геометрия панели и открытые вкладки
  (`settingshub.chat.ui`), как у стека.

## 7. Архитектура и фазы

```
web/chat.js (новый модуль; self-report + EXPECTED-манифест, баннер v86)
  ├─ панель/вкладки/чип: жизненный цикл как stack.js, v85-refit
  ├─ лента, markdown-lite, чипсы вложений, 🔍-вьювер
  └─ fetch только на /settings_hub/chat/*

py/chat_proxy.py (роуты как в stack_store.py)
  ├─ GET  /settings_hub/chat/status        апстрим жив? модель?
  ├─ GET/POST /settings_hub/chat/sessions  список/создать/переименовать
  ├─ GET/PUT/DELETE /settings_hub/chat/session/<id>
  ├─ POST /settings_hub/chat/attach        blob вложения (лимиты)
  ├─ GET  /settings_hub/chat/file/<name>   раздача blob
  ├─ POST /settings_hub/chat/send          сборка payload → апстрим →
  │        {text, thoughts, usage, model, ms}; abort при разрыве клиента
  └─ (v87) POST /settings_hub/chat/load    /v1/load с прогрессом

Тесты: tests/smoke_chat.mjs (jsdom: монтирование, вкладки, настройки,

(сборка payload, сессии, стаб-апстрим) по образцу существующих наборов.

```

| Фаза | Состав |
|---|---|
| **v86 — ядро** | панель + вкладки + 🕘; настройки-секция; OpenAI-compatible URL+ключ; текст, картинки, текстовые файлы; ↻/📋/⏹; статус-строка; smoke_chat + py_test_chat |
| **v87 — медиа+удобства** | видео (кадры py-нарезкой), ✎ редактирование, SSE-стриминг (сервер PolyStrata умеет `stream: true`), `/v1/load` с предупреждением, свой system prompt на вкладку |
| **Спарковано (не обещано)** | интеграция с ComfyUI: drag текста/картинок в ноды и стак, «🚀 в генерацию», сводка воркфлоу 🧩, агентный режим. Владелец решил: чат не агент — трогаем только после стабильности ядра и отдельно согласовываем |

## 8. Риски

1. **Долгая генерация** — таймаут-настройка, ⏹ с первого дня, текст ввода
   не теряется.
2. **Контекст и кадры** — картинки съедают окно: настройки глубины истории
   и размеров; при отказе движка — человеческая причина.
3. **Смена модели = минуты** (PolyStrata) — в v86 только выбор уже
   загруженной; загрузка с прогрессом в v87.
4. **Ключи на LAN** — ключ живёт только в config.json на сервере ComfyUI;
   hint о доверии сети.
5. **Видео без ffmpeg** — функция off с внятной причиной (v76-паттерн).

## 9. v89 — решения владельца (поправки 2026-11-09)

Шесть поправок поверх v88; версии: chat.js/stack.js self-report v89,
py/chat_proxy.py CHAT_SERVER_VERSION v89, entry-баннер + EXPECTED v89.

1. **«Поля настроек без имён»** — все числа ⚙ получают ВИДИМЫЕ мини-подписи
   (2-колоночная сетка `.hub-cs-grid`, label над input'ом, клик по метке
   фокусирует поле); полное объяснение остаётся в тултипе. Плюс отдельные
   строки «context size (0 = auto)» и «timeout, s».
2. **«Показывать занятый и доступный контекст»** — каждый ответ несёт
   `reply.ctx = {used, total, est, images}`; used = `usage.prompt_tokens`
   апстрима (точно, без «≈») либо оценка прокси (chars/4 + 8/сообщение +
   750/картинка, с «≈»); total = cfg `ctx_size` (новая настройка, 0 = авто:
   `/v1/status` → `context.native`, кэш 180 с). Статус-строка: «ctx 3.2k/32k»,
   «⚠» за 90%; ctx хранится на assistant-сообщении — переживает reload.
3. **«Гибкий поиск по сохранённым чатам»** — `GET /chat/sessions?q=`:
   каждое слово (мультислова) должно встретиться в названии ИЛИ в текстах
   сообщений (вместе — комбинированный режим); каждый хит несёт «hit» —
   строку содержания с совпадением. В 🕘 — живой поиск с debounce 250 мс
   и сниппетами под названием.
4. **«Свой путь системных промптов»** — cfg `prompts_dir` (абсолютный или
   относительный к корню ComfyUI), ⚙ → «System prompt catalog» → «Prompts
   folder» (Enter применяет, [default] сбрасывает на PolyStrata-путь);
   каталог read-only, jail пути следует за папкой.
5. **«Список промптов слиплся»** — `.hub-cp-list` — flex-COLUMN с
   max-height, у элементов остался дефолтный `flex-shrink:1`: когда файлов
   больше, чем влезает, КАЖДЫЙ элемент сжимался до пикселей (текст
   обрезался до полосок — скриншот владельца). Фикс: `flex: 0 0 auto` —
   элементы держат высоту, скроллится СПИСОК.
6. **«Где вернуть скрытый чат/стак»** — при выключении обе панели показывают
   toast «ComfyUI Settings → SettingsHub → …», а в их ⚙ под переключателем
   стоит постоянная подсказка; скрытие через родную настройку ComfyUI тоже
   озвучивается.

Попутно: тест-хук `renderStatus`/`fmtTok`/`renderSessList`, фейковый SSE
дон-эвант смоук-теста приведён к форме реального прокси (`session` внутри
`reply`), в py-тестах закрыта утечка `keep_sessions=3` (флаки eviction).
